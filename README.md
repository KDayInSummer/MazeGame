# MazeGame 🎮

基于 Web 技术的交互式迷宫游戏，玩家需要从起点出发，在规定时间内找到通往终点的路径。游戏采用递归回溯算法生成迷宫，支持多种难度级别，并提供 A* 算法路径提示功能。

## ✨ 游戏特性

- 🎯 **迷宫随机生成** - 使用递归回溯算法生成具有唯一路径的迷宫，支持动态分支长度
- ⌨️ **键盘控制** - 支持方向键和 WASD 双套操作方案
- ⏱️ **计时系统** - 实时记录游戏时长，支持暂停/继续
- 📊 **难度选择** - 提供简单、中等、困难三种难度级别
- 💡 **路径提示** - A* 算法计算最短路径，帮助玩家通关
- 🎨 **精美界面** - 渐变背景、流畅动画、响应式布局
- 📱 **跨平台** - 纯前端实现，支持所有现代浏览器

## 🚀 快速开始

### 方式一：直接运行

只需下载 `standalone.html` 文件，用任意现代浏览器打开即可开始游戏：

```bash
# 使用默认浏览器打开
open standalone.html

# 或者直接双击文件
```

### 方式二：本地开发服务器

如需在开发环境中运行：

```bash
# 克隆仓库
git clone <repository-url>
cd MazeGame

# 使用 Python 启动简单服务器
python -m http.server 8000

# 或使用 Node.js
npx serve .

# 访问 http://localhost:8000/standalone.html
```

## 🎯 游戏玩法

### 目标
从绿色起点(S)出发，找到通往红色终点(E)的路径，用时越短得分越高。

### 操作说明

| 按键 | 操作 |
| :--- | :--- |
| ↑ / W | 向上移动 |
| ↓ / S | 向下移动 |
| ← / A | 向左移动 |
| → / D | 向右移动 |
| Space | 暂停/继续游戏 |
| R | 重新开始游戏 |

### 游戏控制

- **开始游戏** - 点击"开始游戏"按钮或按空格键
- **暂停/继续** - 点击"暂停/继续"按钮或按空格键
- **路径提示** - 点击"提示"按钮显示最短路径（扣减 100 分）
- **重新开始** - 点击"重新开始"按钮或按 R 键
- **难度切换** - 从下拉菜单选择不同难度

## 📊 难度配置

| 难度 | 行数 | 列数 | 单元格大小 | 分支长度范围 | 难度奖励 | 推荐人群 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 简单 | 10 | 15 | 40px | 3-8 格 | 0分 | 初学者、儿童 |
| 中等 | 15 | 20 | 30px | 5-12 格 | 200分 | 普通玩家 |
| 困难 | 20 | 30 | 25px | 8-18 格 | 500分 | 高手玩家 |
| 超级困难 | 25 | 35 | 22px | 12-25 格 | 1000分 | 专家玩家 |
| 地狱 | 30 | 45 | 18px | 15-35 格 | 2000分 | 终极挑战 |

### 难度递增说明

- **迷宫规模**：从 10×15 递增到 30×45，单元格从 40px 缩小到 18px
- **分支数量**：从 2% 递增到 25%，高难度有更多干扰性死胡同
- **分支长度**：从 3-8 格递增到 15-35 格，走错代价更高
- **路径复杂度**：每级难度都会急剧增加，地狱模式几乎每步都有多个选择

### 迷宫特性

- ✅ **唯一路径**：始终只有一条从起点到终点的正确路径
- ✅ **无循环路径**：避免可以反复转圈的设计
- ✅ **死胡同干扰**：错误路径会延伸较长距离，增加迷惑性
- ✅ **空间充分利用**：无大块空白区域

## 🏆 计分规则

```
得分 = 基础分 - 时间惩罚 + 难度奖励 - 提示惩罚
基础分 = 1000 分
时间惩罚 = 游戏时长（秒）
难度奖励：简单=0分，中等=200分，困难=500分
提示惩罚：每次提示扣减 100 分
最低得分 = 0 分
```

## 🧠 算法说明

### 迷宫生成：递归回溯算法

递归回溯算法通过深度优先搜索生成迷宫，特点是生成的路径较长，游戏性强。

**算法流程：**
1. 初始化全墙网格，选择起点
2. 标记当前单元格为已访问，压入栈
3. 查找未访问的相邻单元格
4. 随机选择邻居，打通墙壁，递归访问
5. 无未访问邻居时回溯

### 路径提示：A* 算法

A* 算法是一种高效的最短路径搜索算法，评估函数：

```
f(n) = g(n) + h(n)
g(n): 起点到当前节点的实际步数
h(n): 当前节点到终点的曼哈顿距离
```
